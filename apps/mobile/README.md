# Ancien squelette mobile

Ce dossier conserve les sources Expo historiques. Il manque les dépendances, des écrans et la configuration de build. Il ne constitue pas un livrable natif vérifié.

Les anciennes commandes qui affichaient simplement un message de réussite ont été retirées. Pour le cœur Web sur téléphone, utiliser la nouvelle interface responsive de `apps/web`.

La reconstruction native et ses critères figurent dans `../../docs/REPRISE_COMPLETE.md`, étape 10.
